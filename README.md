## 研究方法

- 从产业链和财务报表出发，将主题拆解为可跟踪的关键变量。
- 区分事实、公司指引、市场预期与待验证假设，避免把预期直接当作兑现。
- 结合情景分析、敏感性测算和月度/季度验证清单，形成可复核的跟踪框架。
